# About

This site is generated by the Croupier SSG example: a small static
site generator built on the [Croupier](https://github.com/ralsina/croupier)
task library.

## The Idea

Every markdown file in `content/` gets a render task whose input is
the source and whose output is the HTML page. Croupier tracks the
content hashes, so:

- Editing a page rebuilds exactly that page
- Unchanged pages skip on every run (early cutoff)
- Deleted sources have their outputs cleaned up on the next run

## Try It

Edit this file, run `./bin/ssg` again, and watch only this page
rebuild.
